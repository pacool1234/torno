# ADR-0006: Run TypeScript with Node's native type stripping

- **Status:** Accepted
- **Date:** 2026-10-02

## Context

Node can't execute TypeScript as-is: something has to remove the type annotations first. ADR-0002 chose TypeScript on Node LTS but left open _how_ the code runs.

Node strips types natively: enabled by default since v23.6.0 (v22.18.0 on the 22 line), and stable since v24.12.0 and v25.2.0. Stripping is all it does; it performs no type checking and ignores `tsconfig.json`.

## Decision

- torno runs directly as TypeScript: `node src/main.ts`. No build step and no extra runtime dependency.
- Type checking is a separate step: `pnpm typecheck` (`tsc`, with `noEmit`), run locally and in CI.
- `tsconfig.json` sets `erasableSyntaxOnly`, `allowImportingTsExtensions`, `verbatimModuleSyntax` and `noEmit`, so the compiler rejects anything Node can't strip.
- Minimum Node version: 24.12 (`engines` in `package.json`, `.nvmrc`, CI).

## Alternatives considered

- **tsx.** Supports all TypeScript syntax and runs it the same way, but it's an extra dependency doing what Node now does natively, and it hides what is actually happening.
- **Compile with `tsc`, then run the JavaScript output.** The most conventional approach and needed for publishing a package, but it adds a build step to every run during development, plus output folders and source maps to manage.

## Consequences

- **Relative imports must include the extension:** `./foo.ts`, never `./foo`.
- **Syntax that generates code is unavailable:** `enum`, namespaces with runtime code, and **constructor parameter properties**. Constructor injection (ADR-0001) is therefore written out explicitly: declare the field, then assign it in the constructor. Use union types or `as const` objects instead of enums.
- **Type errors never stop a run.** `node src/main.ts` happily executes code that fails `tsc`. The guarantees come from `pnpm typecheck` and CI, not from running the program.
- **Publishing torno as an installable package** (if ever) will need a build step or a dependency on Node ≥ 24.12 at install time. Revisit then.
